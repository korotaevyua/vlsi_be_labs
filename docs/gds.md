# Генерация GDS

1. В терминале перейдите в папку work/gds с помощью следующей команды (данная команда также создаст нужную папку, если она отсутствует):

```bash
mkdir -p ../gds && cd ../gds
```

Команда выполняется из папки `work/layout`, в которой мы работали на предыдущем этапе. Запустите САПР Magic со специальным вспомогательным файлом для библиотеки Skywater:

```bash
magic -noconsole -dnull -rcfile ../../scr/gds/sky130A.magicrc
```

2. Перейдите в директорию `vlsi_be_labs/scr/gds` (без использования текущей командной строки) и откройте файл `magic.tcl`. Его содержимое приведено ниже:

```tcl
###############################################
#Load tlef and DEF
lef read ../../lefs/sky130.tlef
gds read ../../skywater-pdk/libs.tech/sky130_fd_sc_hd.gds

def read ../layout/final.def -noblockage -labels
################################################
#Set size
set DIE_AREA "0.0 0.0 xxx yyy"

box [lindex $DIE_AREA 0]um [lindex $DIE_AREA 1]um [lindex $DIE_AREA 2]um [lindex $DIE_AREA 3]um
property FIXED_BBOX [box values]
################################################

################################################
#Write GDS
select top cell
cellname filepath seven_segment_seconds .
save

gds readonly true
gds rescale false

load seven_segment_seconds
select top cell

cif *hier write disable
cif *array write disable

gds nodatestamp yes
gds write seven_segment_seconds.gds
################################################
```

В первой части скрипта происходит загрузка исходных данных: TechLEF, GDS файлов ячеек и финального DEF проекта. Далее задаются границы генерируемого GDS. Наконец, в последней части находятся команды, необходимые для генерации GDS в Magic.

3. В строке `set DIE_AREA` вместо xxx и yyy введите полные размеры блока с учетом отступов от ядра. Это значения `DIE_X_size` и `DIE_Y_size`, рассчитанные в скрипте `set_fp.tcl`:

```tcl
set DIE_X_size [expr $X_size + (0.46*2)]
set DIE_Y_size [expr $Y_size + (2.72*2)]
```

Таким образом, к размеру ядра по X необходимо прибавить 0.92 мкм, а по Y - 5.44 мкм. Сохраните файл `magic.tcl`.

4. Вернитесь в командную строку Magic и запустите скрипт с помощью команды:

```tcl
source ../../scr/gds/magic.tcl
```

Данный скрипт выпишет финальный GDS файл блока, используя GDS всех используемых в проекте ячеек. В случае успешного выполнения в директории `work/gds` появится файл `seven_segment_seconds.gds`.

Просмотрите финальный GDS файл `seven_segment_seconds.gds` с помощью KLayout.
