# Основы TCL и Bash

TCL - высокоуровневый скриптовый язык, интегрированный во многие САПР для разработки микроэлектроники, включая используемые в данной работе. Это означает, что команды САПР можно использовать в скриптах, написанных на TCL, что позволяет автоматизировать большое количество задач.

Далее приведена краткая памятка по языку TCL, затрагивающая исключительно синтаксические конструкции, используемые в данной работе. Для успешного прохождения работы не требуется писать скрипты на языке TCL, поэтому ознакомление с памяткой можно пропустить без потери возможности прохождения работы, однако знакомство с TCL поможет лучше понять используемые команды и сценарии их использования. Для более детального изучения TCL рекомендуем обратиться к специализированной литературе.

```tcl
# так выглядит комментарий на новой строке
set a 1 ; # для встроенного в строку комментария ставится ; перед решеткой

set X_size 100 ; # объявляем переменную X_size и присваиваем ей значение 100
puts $X_size ; # используем переменную с помощью символа $ и выводим ее значение

set inputs [all_inputs] ; # присваиваем результат выполнения команды САПР all_inputs

# Для перехода на новую строку в рамках одной команды используется символ \
set a \
1

set input_pins {} ; # объявление пустого списка input_pins
lappend input_pins $X_size ; # добавить значение переменной в список

# foreach присваивает каждое значение из списка переменной
# и выполняет блок кода, заключенный в фигурные скобки
foreach input $inputs {
    lappend input_pins [get_full_name $input]
}

# Цикл for с увеличением индекса i
# Значения выводятся до тех пор, пока выполняется условие
for {set i 0} {$i < 5} {incr i} {
    puts $i
}

source script.tcl ; # запуск скрипта
expr 2 + 2 ; # выполнение вычислений
```

Так как большая часть работы с САПР будет проходить в командной строке, рассмотрим минимальный набор команд Bash - командной оболочки Unix систем, который понадобится для работы в терминале.

```bash
cd dir # перейти в директорию dir
cd .. # перейти в родительскую директорию
ls # вывести список содержимого директории
cat file # вывести в терминал содержимое файла file
```

Для быстрой работы в терминале рекомендуется применять клавишу «стрелка вверх» для возврата к предыдущей введенной команде.
